# Support

OpenMergeLens is maintained on a best-effort basis.

- Use [Discussions](https://github.com/suguspnk/openmergelens/discussions) for
  setup help, usage questions, and ideas.
- Use the
  [bug form](https://github.com/suguspnk/openmergelens/issues/new?template=bug.yml)
  for reproducible defects.
- Use the
  [feature form](https://github.com/suguspnk/openmergelens/issues/new?template=feature.yml)
  for focused proposals.
- Use
  [private vulnerability reporting](https://github.com/suguspnk/openmergelens/security/advisories/new)
  for security issues.

Before requesting help, run `openmergelens --version`, `node --version`,
`gh --version`, and the reviewer CLI's version command. Include those versions,
your operating system, reproduction steps, and sanitized diagnostics. Never
post credentials, private pull-request content, or unredacted logs.

Only the latest published OpenMergeLens version is actively supported.
Maintainers cannot provide support for GitHub, GitHub CLI, npm, operating-system
schedulers, or third-party reviewer subscriptions beyond diagnosing how they
interact with OpenMergeLens.
